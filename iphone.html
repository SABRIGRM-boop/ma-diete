Ouvrir Ma Diète

Mettre l'icône D sur ton iPhone

  1. Reste sur cette page, sans appuyer sur « Ouvrir Ma Diète ».
  2. Appuie sur le bouton Partager de Safari (le carré avec une flèche vers le haut).
  3. Choisis Sur l'écran d'accueil. L'icône D est déjà proposée.
  4. Si tu vois « Ouvrir comme app web », désactive-le.
  5. Appuie sur Ajouter.

L'icône D ouvre cette page : appuie alors sur « Ouvrir Ma Diète ».

Pour ouvrir l'app directement

Cette méthode évite le bouton ci-dessus, mais passe par les Réglages.

Installer le profil

Appuie sur Autoriser, puis ouvre Réglages, Profil téléchargé, Installer. iPhone affiche « Non signé » : c'est normal, le profil ajoute seulement l'icône. Tu peux le retirer dans Réglages, Général, VPN et gestion de l'appareil.
